8. Централизованная навигация через faces-config.xml
   Статус

Принято
Контекст

Приложение имеет несколько страниц (index.xhtml, main.xhtml, architecture.xhtml, wiki-embed.xhtml). Требуется управлять переходами между ними предсказуемо и в одном месте.
Решение

Определить правила навигации в faces-config.xml:

    Явные navigation-case для каждого исхода (goToMain, goToArchitecture, goToIndex).

    Использование from-view-id для ограничения правил конкретными страницами.

    Отказ от неявной навигации через возврат строки в бинах в пользу чёткой декларативной конфигурации.

Последствия

    Читаемость и поддерживаемость потоков навигации в одном XML-файле.

    Лёгкость добавления новых страниц и переходов.

    Некоторая избыточность по сравнению с неявной навигацией JSF.

    Требует знания структуры faces-config.xml для разработчиков.
