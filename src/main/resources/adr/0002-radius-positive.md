# 2. Требование положительного значения радиуса

## Статус
Принято

## Контекст
Математическая модель проверки попадания точки предполагает радиус как положительную величину.

## Решение
Ограничить выбор радиуса значениями > 0.

## Последствия
- Предотвращение математических ошибок
- Более интуитивный интерфейс
- Упрощение алгоритма проверки
