# 1. Выбор JSF в качестве фреймворка представления

## Статус
Принято

## Контекст
Требовалось выбрать технологию для веб-интерфейса с поддержкой Jakarta EE 10.

## Решение
Выбран Jakarta Server Faces (JSF) 4.0 с PrimeFaces 13.0.

## Последствия
- Полная интеграция с Jakarta EE CDI
- Наличие готовых компонентов через PrimeFaces
- Сложность настройки для начинающих
- Высокая производительность в enterprise-средах
