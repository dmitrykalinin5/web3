# 4. Интерактивный график на Canvas
   Статус

## Принято
## Контекст

## Требуется визуализировать область попадания и точки на графике, позволяя пользователям добавлять точки щелчком мыши. График должен динамически масштабироваться при изменении радиуса R.
## Решение

### Использовать HTML5 Canvas с JavaScript для отрисовки:
- Области (квартал окружности, треугольник, прямоугольник) с заливкой.
- Координатной сетки и осей.
- Точек из истории результатов.
- Обработки кликов для добавления новых точек с конвертацией координат.

## Координаты графика синхронизируются с формой через скрытые поля и AJAX-запросы.
## Последствия
- Богатая интерактивная визуализация без перезагрузки страницы.
- Прямая манипуляция графиком как способ ввода.
- Сложность реализации точного преобразования координат Canvas ↔ математические.
- Необходимость поддержки состояния графика при смене R.
