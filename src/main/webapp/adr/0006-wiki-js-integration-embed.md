# 6. Интеграция с Wiki.js для контекстных обучающих материалов

## Статус
Принято

## Контекст
Требуется связать результаты работы приложения (значение радиуса R) с обучающими материалами во внутренней системе знаний (Wiki.js). Пользователь должен видеть релевантную статью, объясняющую математические концепции, связанные с выбранным радиусом.

## Решение
Реализовать сервис `WikiService` и бин `WikiBean`:
- Маппинг радиусов на статьи: Предопределённый `Map<Double, String>` сопоставляет значения R (1.0, 1.5, ...) со slug статей Wiki.js
- Генерация ссылок: Методы `getArticleEmbedUrl()` возвращают URL для встраивания статьи через iframe (`/api/page/{slug}/embed`)
- Встраивание на отдельной странице: Страница `wiki-embed.xhtml` отображает статью в iframe с параметром радиуса из запроса
- Резервная статья: При отсутствии маппинга используется статья по умолчанию ("mathematics-intro")

## Последствия
- Обогащение приложения обучающим контентом, адаптированным к вводимым данным
- Wiki.js можно обновлять и пополнять независимо от кода приложения
- Зависимость от доступности и API Wiki.js (риск недоступности внешнего сервиса)
- Необходимость настройки CORS или прокси для встраивания iframe с другого домена
- Отделение контента от кода улучшает поддерживаемость
