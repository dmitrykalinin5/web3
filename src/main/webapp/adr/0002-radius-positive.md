# 2. Требование положительного значения радиуса

## Статус
Принято

## Контекст
Математическая модель проверки попадания точки в область предполагает радиус как положительную величину. Радиус используется для определения границ области в нескольких квадрантах (квартал окружности, треугольник, прямоугольник). Отрицательный или нулевой радиус приведет к математическим ошибкам и некорректному определению области попадания.

## Решение
Ограничить выбор радиуса значениями строго больше 0. Валидация выполняется как на клиентской стороне (в интерфейсе), так и на серверной стороне перед выполнением вычислений.

## Последствия
- Предотвращение математических ошибок при вычислении области попадания
- Более интуитивный интерфейс для пользователя
- Упрощение алгоритма проверки попадания точки
- Необходимость реализации валидации на обеих сторонах (клиент/сервер)
