# 3. Выбор PostgreSQL в качестве базы данных

## Статус
Принято

## Контекст
Необходимо выбрать систему управления базами данных для хранения результатов проверки точек. Требования включают: надежность, поддержку транзакций, интеграцию с Jakarta EE через JPA, и возможность работы в enterprise-среде.

## Решение
Выбран PostgreSQL в качестве СУБД. Подключение осуществляется через JTA DataSource (`java:jboss/datasources/PostgresDS`) с использованием Hibernate в качестве JPA-провайдера.

## Последствия
- Надежное хранение данных с поддержкой ACID-транзакций
- Хорошая интеграция с Jakarta EE через JPA/Hibernate
- Отличная производительность и масштабируемость
- Поддержка сложных типов данных при необходимости
- Требуется настройка DataSource на сервере приложений
