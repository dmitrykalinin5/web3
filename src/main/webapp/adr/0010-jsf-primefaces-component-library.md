# 10. Выбор PrimeFaces в качестве компонентной библиотеки для JSF

## Статус
Принято

## Контекст
JSF предоставляет базовые компоненты, но для создания современного UI с богатыми элементами (слайдеры, расширенные таблицы, панели) требуется сторонняя библиотека компонентов. Необходимо выбрать компонентную библиотеку, которая интегрируется с JSF и предоставляет широкий набор готовых компонентов.

## Решение
Использовать PrimeFaces 13.0 как основную компонентную библиотеку:
- `<p:slider>` для выбора координаты X с визуальной обратной связью
- `<p:dataTable>` с пагинацией для отображения истории результатов
- `<p:selectOneMenu>` для выбора радиуса R
- `<p:panel>` и `<p:panelGrid>` для структурирования страниц ADR
- Интеграция AJAX (`<p:commandButton>`, `update`, `process`) для динамического обновления без перезагрузки страницы

## Последствия
- Значительное ускорение разработки UI благодаря готовым компонентам
- Современный внешний вид и поведение "из коробки"
- Увеличение размера загружаемых ресурсов (CSS/JS библиотеки)
- Обучающий порог для разработчиков, не знакомых с PrimeFaces
- Хорошая документация и активное сообщество
