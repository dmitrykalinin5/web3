# 1. Выбор JSF в качестве фреймворка представления

## Статус
Принято

## Контекст
Требовалось выбрать технологию для веб-интерфейса с поддержкой Jakarta EE 10. Необходим фреймворк, который обеспечивает хорошую интеграцию с серверной частью Java и поддерживает современные подходы к разработке веб-приложений.

## Решение
Выбран Jakarta Server Faces (JSF) 4.0 с PrimeFaces 13.0 в качестве компонентной библиотеки.

JSF предоставляет:
- Полную интеграцию с Jakarta EE CDI для управления зависимостями
- Компонентную модель разработки UI
- Встроенную поддержку AJAX
- Соответствие стандартам Jakarta EE

## Последствия
- Полная интеграция с Jakarta EE CDI, что упрощает внедрение зависимостей
- Наличие готовых компонентов через PrimeFaces ускоряет разработку UI
- Сложность настройки для начинающих разработчиков
- Высокая производительность в enterprise-средах
- Связь с серверной логикой через управляемые бины
