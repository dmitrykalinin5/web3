# 11. Использование Hibernate в качестве JPA-провайдера

## Статус
Принято

## Контекст
Для работы с базой данных через JPA необходим провайдер, который реализует спецификацию Jakarta Persistence API. Требуется выбрать провайдер, который обеспечивает хорошую производительность, поддерживает PostgreSQL и предоставляет расширенные возможности.

## Решение
Выбран Hibernate ORM 6.2.7 в качестве JPA-провайдера. Конфигурация выполнена через `persistence.xml` с настройками:
- Диалект PostgreSQL: `org.hibernate.dialect.PostgreSQLDialect`
- Автоматическое обновление схемы: `hibernate.hbm2ddl.auto=update`
- Пул соединений размером 10
- Batch-обработка с размером 20

## Последствия
- Мощный и зрелый ORM-фреймворк с широкими возможностями
- Отличная поддержка PostgreSQL и других СУБД
- Автоматическое управление схемой базы данных через `hbm2ddl.auto`
- Хорошая производительность благодаря кэшированию и оптимизациям
- Расширенные возможности (HQL, критерии API, события жизненного цикла)
- Потенциальная сложность для начинающих разработчиков
