# 5. Динамическая загрузка и "живая" перезагрузка ADR

## Статус
Принято

## Контекст
ADR должны быть "живой документацией", обновляемой без перезапуска приложения при изменении файлов. Файлы ADR хранятся в ресурсах (`/adr/*.md`). Необходимо обеспечить автоматическое обновление содержимого при изменении файлов ADR.

## Решение
Реализовать сервис `ADRService` со следующими механизмами:
- Парсинг Markdown: Регулярные выражения для извлечения полей (ID, заголовок, статус, контекст, решение, последствия)
- Кэширование: `LinkedHashMap` для хранения распарсенных ADR в памяти
- Наблюдение за файлами: `WatchService` отслеживает изменения в директории ADR и автоматически перезагружает кэш при создании, изменении или удалении файлов
- Application-scoped Bean: `ADRBean` предоставляет список ADR для JSF-страницы

## Последствия
- Документация всегда актуальна, изменения отображаются в реальном времени
- Нет необходимости в перезапуске сервера или ручном обновлении
- Риск некорректного парсинга при нестандартном формате Markdown
- Зависимость от файловой системы в развертываемой среде (проблемы с путями в WAR/JAR)
- Дополнительная нагрузка на систему при мониторинге файлов
