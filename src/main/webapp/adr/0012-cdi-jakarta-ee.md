# 12. Использование CDI (Contexts and Dependency Injection) для управления компонентами

## Статус
Принято

## Контекст
Необходимо выбрать подход к управлению зависимостями и жизненным циклом компонентов приложения. Требуется решение, которое интегрируется с Jakarta EE и обеспечивает инверсию управления (IoC) и управление контекстами (Application, Session, Request).

## Решение
Использовать Jakarta CDI (Contexts and Dependency Injection) API 4.0 для:
- Управления зависимостями через аннотации `@Inject`
- Управления контекстами: `@ApplicationScoped`, `@SessionScoped`, `@RequestScoped`
- Интеграции с JSF через аннотацию `@Named`
- Управления транзакциями через `@Transactional`

Распределение контекстов:
- `@ApplicationScoped`: Сервисы, репозитории, конфигурация (один экземпляр на приложение)
- `@SessionScoped`: Управляющие бины пользовательских данных (один экземпляр на сессию)
- `@RequestScoped`: Временные компоненты, создаваемые на каждый запрос

## Последствия
- Естественная интеграция с Jakarta EE и JSF
- Упрощение тестирования благодаря инверсии зависимостей
- Автоматическое управление жизненным циклом компонентов
- Эффективное использование памяти через правильное распределение контекстов
- Уменьшение связанности компонентов
- Требуется понимание контекстов CDI для правильного выбора scope
